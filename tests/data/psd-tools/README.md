# Photoshop test files

These PSD files were saved by Adobe Photoshop and come from the
[psd-tools](https://github.com/psd-tools/psd-tools) project (`tests/psd_files`, commit
`b58704c1c9c9`), used under the MIT license in [LICENSE](LICENSE).
File names are the original paths with `/` replaced by `_`.

PairPaint's tests open each file, render its layers and compare the result with the
flattened image Photoshop stored in the same file.
